# Data Cleaning Portfolio

A sample dataset cleaned to show how I approach fixing messy, real-world data.

## What's Inside

- `messy-data.xlsx` / `messy-data.csv`: the raw data, with problems like duplicate rows, inconsistent formatting, typos, and missing fields
- `cleaned-data.xlsx` / `cleaned-data.csv`: the same data, cleaned
- `cleaning-log.md`: notes on what was wrong and how I fixed it

## Skills

- Identifying and removing duplicate records
- Standardizing formatting (names, dates, phone numbers, emails)
- Fixing data entry typos without changing what the data actually meant
- Keeping missing data honest instead of filling it in with guesses
